# README Updater Memory

## README の構造（セクション順）

1. タイトル・概要
2. スクリーンショット（手動管理）
3. ダウンロード（手動管理）
4. 主な機能（手動管理）
5. 技術スタック
6. プロジェクト構造
7. セットアップ（手動管理）
8. Claude Code
   - プロジェクト設定（CLAUDE.md）
   - スキル（Skills）← `.claude/skills/` と同期
   - サブエージェント（Agents）← `.claude/agents/` と同期
   - Hooks ← `.claude/settings.json` と同期
9. ライセンス（手動管理）
10. 参考リンク（手動管理）

## 管轄外セクション（変更しない）

概要・スクリーンショット・ダウンロード・主な機能・セットアップ・ライセンス・参考リンク

## エージェントテーブルの慣習

- `regression-reviewer` のようにチェック項目を持つエージェントは、
  テーブルの直後に「チェック項目テーブル」と「追記方法」の説明を記載する

## 既存エージェント一覧（2026-03-22 時点）

- `ui-ux-designer`: UI/UX レビュー・改善提案・実装
- `regression-reviewer`: デグレ再発防止チェックリストによる静的レビュー
- `readme-updater`: README とプロジェクト実態の同期
- `icon-replacer`: Android・iOS アイコン・スプラッシュスクリーン一括差し替え

## 更新パターン

### エージェント追加時
- サブエージェントテーブルの末尾に行を追加する
- エージェント名はバッククォートで囲む（例: `icon-replacer`）
- 説明はエージェント `.md` の先頭数行（目的・入力・動作）から1〜2文で要約する
