# 初回 UI/UX レビュー（2026-03-14）

## 対象画面
HomeScreen, NoteScreen, AreaShopListScreen, ShopScreen, EditShopScreen, HistoryScreen, ScheduleScreen

## 高優先度

### タッチターゲットサイズ不足（アクセシビリティ）
- ScheduleScreen の行内アイコン（食レポ・編集・削除）が `.size(24.dp)` のみ
- ShopScreen のお気に入りボタン 32dp、ReportCard のシェアアイコン 20dp
- Material Design 3 / WCAG 2.1 AA 基準では最低 48×48dp
- 修正方針: `IconButton` に置換

### EditShopScreen 削除ボタンの視覚的差別化不足
- 「編集を保存」と「削除」が同じ `MaxWidthButton` スタイル
- 削除は非可逆操作のため `errorColor` を使った `OutlinedButton` に変更すべき

### 空状態（Empty State）の改善
- NoteScreen・AreaShopListScreen・HistoryScreen・ScheduleScreen でテキスト1行のみ
- アイコン・イラスト・アクションボタンを含む案内エリアに改善すべき

### URL リンク色のハードコード
- ShopScreen の `UrlItem` が `Color.Blue` をハードコード
- ダークモードで背景との対比が崩れる
- 修正: `MaterialTheme.colorScheme.primary` に変更

### 年月グループヘッダーのフォーマット
- HistoryScreen・ScheduleScreen が `"2024-01"` 形式
- `"2024年1月"` への変更で可読性向上

## 中優先度

### Theme.kt カラースキーム
- `mediumContrastLightColorScheme` / `mediumContrastDarkColorScheme` を常時適用
- OS のアクセシビリティ設定に応じて動的切り替えすべき
- `mediumContrastLightColorScheme` の `background` に `onPrimaryLightMediumContrast` が誤代入の疑い

### ActionButton の Material3 置換
- `Box + clickable` 自作実装でリップルエフェクト・セマンティクスなし
- `Button` + `ButtonDefaults.buttonColors(containerColor = MaterialTheme.colorScheme.tertiaryContainer)` に置換

### ShopInputField → OutlinedTextField 移行
- `BasicTextField` + 手動ボーダーでフォーカス時のボーダー色変化なし

### AppBar の実装刷新
- `actions` スロットに透明アイコンを入れてタイトルをセンタリングする非標準実装
- `Icons.Default.ArrowBack` → `Icons.AutoMirrored.Filled.ArrowBack` 推奨

### collectAsState → collectAsStateWithLifecycle 移行
- HistoryScreen・ShopScreen 等で `collectAsState()` 使用

## 低優先度
- Typography の充実（`bodyLarge` のみカスタム定義）
- DatePickerDialog のボタンラベルを日本語化（「決定」「キャンセル」）
- ShopDetailItem のパディング拡大（`vertical = 2.dp` → `8dp` 程度）
- HistoryButton のアイコン修正（`ramen_dining_24px` → `history_24px` 等）
